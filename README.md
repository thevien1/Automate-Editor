## 🚀 Tính Năng Nổi Bật

### 1. Thiết Kế Kịch Bản Kéo - Thả Trực Quan (No-Code Flow)
- Kho thư viện với hơn 100+ khối lệnh chức năng phong phú:
  - **Điều hướng & Tương tác**: Mở trang web, Click chuột, Nhập văn bản, Cuộn trang mượt mà (Smooth Scroll), Chờ đợi phần tử (Wait for element).
  - **Logic & Điều khiển luồng**: Rẽ nhánh điều kiện (If / Else), Vòng lặp (Loop / For-each), Thử lại (Try / Catch).
  - **Chuột & Bàn phím ảo**: Mô phỏng hành vi di chuyển chuột ngẫu nhiên giống người thật (Human-like Virtual Mouse & Keyboard) chống phát hiện hành vi bot.

### 2. Tích Hợp Dữ Liệu Mạnh Mẽ
- Đọc/ghi dữ liệu từ file **Excel (.xlsx), CSV, Text (.txt)**.
- Quản lý biến dữ liệu động, xử lý chuỗi ký tự (Split, Replace, Regex).
- Tự động hóa điền form, nuôi tài khoản số lượng lớn từ file dữ liệu đầu vào.

### 3. Đồng Bộ Liền Mạch Với SV Browser
- Tự động kết nối tới [**SV Browser**](https://github.com/thevien1/SV-Browser) qua cổng API nội bộ `http://localhost:8725`.
- Đọc và hiển thị toàn bộ danh sách profile từ SV Browser để bạn chọn profile chạy kịch bản.
- Tự động khởi chạy trình duyệt, gán Proxy, mở kịch bản và thu dọn tiến trình khi hoàn thành.

### 4. Đa Luồng (Multi-threading) Tốc Độ Cao
- Cho phép chạy song song nhiều luồng trình duyệt cùng lúc.
- Bảng điều khiển giám sát tiến trình trực quan theo thời gian thực.

## 💻 Yêu Cầu Hệ Thống
- **Hệ điều hành**: Windows 10, Windows 11 (64-bit).
- **Bộ nhớ RAM**: Tối thiểu 4 GB (Khuyến nghị 8 GB trở lên nếu chạy đa luồng).
- **Phần mềm đi kèm**: Cài đặt cùng [**SV Browser**](https://github.com/thevien1/SV-Browser) để đạt hiệu năng tốt nhất.

---

## 📖 Hướng Dẫn Nhanh

1. Tải và cài đặt phần mềm **SV Browser** và **SV Browser Automate Editor**.
2. Khởi động **SV Browser** trước để kích hoạt cổng kết nối API cục bộ.
3. Mở **SV Browser Automate Editor**, tạo một dự án kịch bản mới (New Project).
4. Kéo thả các khối lệnh theo quy trình bạn muốn tự động hóa.
5. Bấm nút **"Run"** để tận hưởng sự tiện lợi của tự động hóa!
